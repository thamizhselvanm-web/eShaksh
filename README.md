# eShaksh

## MPLADS Expenditure Intelligence & Anomaly Triage System

eShaksh is an AI-powered expenditure intelligence platform featuring real-time anomaly triage, vendor network analysis, ground-truth verification, and cost realism engine for MPLADS (Member of Parliament Local Area Development Scheme).

### Features
- **Anomaly Triage Engine**: Real-time detection of financial deviations and suspicious disbursements.
- **Vendor Graph Network**: Network mapping for identifying vendor clustering and collusion risks.
- **Ground-Truth Verification**: Geo-tagged and timestamped field attestation evidence.
- **Cost Realism Engine**: Dynamic benchmarking against localized market rates.

### Getting Started

#### Prerequisites
- Node.js (v18+)
- npm

#### Installation
```bash
npm install
```

#### Running Development Server
```bash
npm run dev
```

#### Building for Production
```bash
npm run build
```
